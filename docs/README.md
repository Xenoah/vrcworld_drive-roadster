# Drive Roadster World — 設計資料

VRChat向けのオリジナル電動スポーツカー走行ワールドの実装前設計です。地上走行、壁走り、飛行、フリー練習、タイムアタック、マルチプレイを扱います。

- [ワールド設計](WORLD_DESIGN.ja.md): 見た目、走行、同期、周回判定、制作順、テストと初期性能目標
- [Unity実装引き継ぎ](UNITY_HANDOFF.ja.md): 環境が使用可能になった時点の開始手順と最初の完了条件
- [公式資料と確認状態](REFERENCES.ja.md): 事実、設計提案、未確認事項の区別

## 現在の状態

本READMEは初期設計資料の索引です。その後モデル・コース・UdonSharpソース・Editor builderを作成しました。最新状況はルートREADMEとIMPLEMENTATION_STATUS.ja.mdを参照。Unityビルド・VRChat実機・複数人同期・VR快適性は未検証です。

想定リポジトリ名は `vrcworld_drive-roadster`。初期調査では対象が見つからず、その後ユーザー承認により公開リポジトリを新規作成しました。

最初は1車種・1台・短い周回コースを完成させ、同期と快適性を確認後、4台の車両プールへ広げます。大規模マップを先に作る計画ではありません。
