## ゲーム独自の設計

海岸の景観、空中リング、周回レイアウト、通常のバンク、タイムアタック、壁面吸着、長い飛行アシストはゲーム用の創作。映像にそのまま存在するとは扱わない。参考映像の印象を取り入れつつ、初見のプレイヤーが進路を読みやすいゲームコースへ変換する。

寸法・車重・推力・航続時間等は映像から確定できない。ゲーム用車体寸法と物理値は独自に設定したもので、実車の仕様値ではない。

## スラスター・着地の再観察

Kickflip 20.4 / 21.6 / 21.9〜22.4 / 25.1秒、Ramp 23.9〜24.4 / 25.9 / 27.6秒を再観察しました。車体追従の細い噴流、接地前からの雲、停止後の残留霧を区別しています。接地瞬間と反発は濃霧で隠れるため、実車の減速度・サスペンション特性は断定しません。[時刻別の観察とゲーム設計への対応](THRUSTERS.ja.md)。
