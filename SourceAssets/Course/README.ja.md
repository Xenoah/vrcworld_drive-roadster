# VECTOR / Coastal 01 — コース資産

ゲーム用オリジナルの海岸テスト施設。実在のTesla施設、実車の実証コース、映像中の配置の再現ではありません。Unity/VRChatでの実機走行・ビルド・マルチプレイは未検証です。

## 内容
- 幅18m、平面曲率半径90m、全長約1.13km（飛行直線を含む概算）
- 加速直線→連続曲面72°バンク→高さ10mの離陸→3個の飛行ゲート→幅32mの着地帯→帰還
- 分離したピット4区画、スラローム練習パッド、観戦デッキ、管制塔、海面/岩礁
- 白灰色セラミック、暗色構造材、細いシアン誘導、方向矢印、制動距離看板、番号付きリング
- 8つの共有材質。テクスチャ不要。装飾にcolliderなし

## ファイル
- build_course.py: Blender 4.3.2で再生成する原本
- VectorCoastal_Course.blend: 編集可能な全景と3つのQAカメラ
- preview_aerial.png / preview_ground.png / preview_wall.png: Blenderのプレビュー。Unity画面ではない
- ../../Assets/DriveRoadster/Art/Course/VectorCoastal_Course.fbx / .glb: LOD0、衝突専用メッシュ、チェックポイントempty
- *_LOD1_VisualOnly.fbx / .glb: 遠景用の任意表示差替え。colliderを含まない
- course_manifest.json: 統合用の正確な座標、順序、幅/高さ/向き、飛行開始/終了、復帰点
- geometry_validation.json: 自動幾何検証結果

## 座標と統合
単位m。manifestはUnityのX右/Y上/Z前。Blender内部は(x,-z,y)。FBXはaxis_forward=-Z、axis_up=Y。最初にUnityのCP_00_START、CP_01_ACCELをmanifestと照合し、鏡像・回転・倍率を確認してください。FBX独自custom propsは補助情報であり、Unityのtag/layer設定を自動生成するものではありません。

VIS_だけを描画。COL_はMeshRendererを無効にしてstatic non-convex MeshColliderとして使用。壁面COL_WallRide_WallArcを壁走り対象レイヤー/コンポーネントに登録し、一般の路面や装飾に吸着させない。COL_Ground_ObservationDeckは歩行者面で、コース判定から除外。最終的なコライダーの向きとraycast接地はUnityで必ず検証。

メイン周回のゲートは0 START、1 ACCEL、2 WALL_APEX、3 LAUNCH、4～6 AIR、7 LANDING、8 RETURN、9 FINISH。FINISHはSTARTと同位置。spawnはSTARTの12m手前。ゲートごとの幅/高さは全幅、depthは全厚12m。ゲート面の前後位置交差検証を使い、高速時のTrigger抜けを防いでください。リングの正方形gate領域は円形開口より広いため、ゲーム側で円形/楕円通過判定を追加すれば厳密にできます。

通常路面は終端の位置・横断方向を共有して連結。意図した離陸〜着地の空隙のみ非接続。地面に接しない装飾基盤は走行面でなく、落下時は復帰制御を使う。空中リングの枠は装飾で、接触衝突による急停止を発生させない。

## 予算とLOD
LOD0は50k三角形以下、collisionは2k以下を目標。実数はmanifest/geometry_validation.json参照。LOD1は小物・建築・岩礁等を38%へ簡略化し、主走行路は保持。全景を一度に切り替えるのは近景に不適切なので、初版ではLOD0固定で計測し、必要に応じて空間分割LODに進む。LOD1切替距離はUnity未調整。8材質の静的バッチ候補だが実drawcall、影、ライトマップ、GPU時間は未計測。

海は不透明で広範な透明オーバードローを使わない。Blenderのpreview太陽/環境照明はFBXへ含めない。Unityではベイク/ライトプローブ/反射設定を別途行う。UVライトマップの生成と重なり検査が必要。

## 未検証項目
飛行は離陸後に高度保持するだけでは着地できず、降下入力/アシストが必要。壁吸着・離脱・横断継ぎ目・着地安定性・逆走・ショートカット・競技時間・VR快適性・ネットワーク・4台負荷をUnity/VRChat実機で検証。90〜150秒の周回目標を達成したという証拠はまだない。

## 自由練習専用・天井接地ラボ
公式の水平灰色天井への逆さ接地写真を視覚参考に、競技外のCeiling Labを独自追加。幅12m、x=110、z=150→210で0→180°へ滑らかにねじり、z=210〜240で高さ18mの水平天井、z=240→300で地上へ連続復帰。推奨12m/s。接地面はCOL_WallRide_CeilingLab。下の60×180mキャッチ/帰還パッドはCOL_Ground_CeilingCatch。入口は練習パッド北側から地続き、出口は同じ地上パッドへ戻る。失敗時は既存の手動リセット/落下復帰でpractice_spawnへ戻す。天井での速度ゼロ吸着、天井からの離脱、車体/アバター姿勢、退出と復帰は実機未検証。タイムアタックには含めず、機能と安全性の検証後に競技採用を判断する。

## 動画観察後の追加・垂直カールランプ
公式Tesla X「Real life, baby」 https://x.com/Tesla/status/2110913438293647789 の実再生フレームを直接確認（4.10秒: 地上から進入、10.30秒: 上端から離脱、17.70秒: 高所の車両と路面）。細幅の灰色走行面、白い一本中央線、赤い両端灯列、黒い背面トラス、地面から垂直へ立ち上がり上端が進入方向へ返るカールを観察して、独立試験施設へ反映しました。撮影は夜間の黒い平坦舗装。海岸やリングは映像に基づきません。

追加ランプは幅6m、半径30m、縦方向125°の円弧、高さ約47.2mというゲーム用の仮寸法。実物の寸法・正確な曲線・速度を測定/再現したとは主張しません。x=240の独立パッドに設置し、中央線/赤縁灯/背面トラスを追加。COL_WallRide_VerticalCurlで接地、下はCOL_Ground_CurlSafetyPad。上端は意図した空中離脱で地上への自動連続帰還路ではないため、自由練習専用・手動リセットで退出と明示。飛行・上下反転・安全退出を実機確認するまでは競技へ採用しません。灰色の水平天井と地上への連続復帰を試す用途は別のCeiling Labが担当します。

### 初期ランタイムとの境界
飛行アシストはメイン周回のLAUNCH〜リング区間だけで有効（フリー走行でも同区間を利用可能）。Vertical Curlの上端離脱は現段階では通常重力による弾道落下であり、このラボは壁/曲面/弾道離脱の試験用。動画の推進/姿勢制御による演技を再現したものではない。区域別飛行アシストは今後の実機検証項目。
